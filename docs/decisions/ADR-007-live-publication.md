# ADR-007 — Publicação sem snapshots no MVP

**Status:** Aceito

## Decisão

Publicar altera o status do menu. Depois disso, edições salvas passam a aparecer na página pública; não haverá versões/snapshots no MVP.

## Consequências

O fluxo é simples e cumpre atualização instantânea. Rascunho paralelo e rollback editorial ficam para evolução futura.
