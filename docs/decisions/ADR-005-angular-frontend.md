# ADR-005 — Angular 22 no frontend

**Status:** Aceito

## Decisão

Reconstruir o frontend com Angular 22 standalone, signals, RxJS, Tailwind e Angular CDK. Não usar bibliotecas exclusivas do ecossistema React.

## Consequências

Ganha-se estrutura consistente para o SaaS; componentes visuais do protótipo serão refeitos, não migrados mecanicamente.
